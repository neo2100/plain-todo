# Shortcuts & syntax

Also available in the app via the **?** button in the top bar.

## Typing (inline conversion)
| Type this at the start of a line | Becomes |
|----------------------------------|---------|
| `[] ` or `[ ] ` | a checkbox **task** |
| `- ` | a bullet **note** |
| `# ` | a **section** title |

## Keys
| Key | Action |
|-----|--------|
| `Enter` | New line below (keeps the same type) |
| `Tab` | Indent — make the line a sub‑item |
| `Shift` + `Tab` | Outdent one level |
| `Backspace` at start of an empty line | Merge into the line above |
| `↑` / `↓` | Move between lines |

## Mouse / touch
| Action | Result |
|--------|--------|
| Drag the ⠿ handle | Reorder within a day, move to another day, or drop on the Backlog |
| `+` (hover a row) | Insert a new line right below |
| Archive icon on a task | Send the task (and its notes/sub‑tasks) to the Backlog |
| Check a parent task | Checks its sub‑tasks; the parent auto‑checks when all children are done |

## Views
- **Rich** — interactive checkboxes and drag‑and‑drop.
- **Plain** — raw text for one day.
- **Single file** — every day in one big text file (`=== YYYY-MM-DD ===` separates days).
  Select several lines and use the **Task / Note / Section** buttons to bulk‑convert.
